# 智能跟随飞行电子宠物

本仓库保存《低成本智能跟随飞行电子宠物设计说明书》，介绍一套面向人机交互与自主跟随的微型四旋翼系统方案。

## 方案概述

- 手机负责语音交互、AI 意图理解和高层动作请求。
- 机载 ESP32-S3 负责指令校验、行为状态机、传感器数据处理、飞控和安全管理。
- 两枚机载 DWM1000 模块与用户携带的 UWB 信标组成测距系统；方案提出通过主动旋转测量研究双测距的镜像歧义。
- OLED 表情和手机状态反馈用于人机交互。

## 当前状态

项目处于方案设计和验证规划阶段，尚未完成整机搭建与飞行验证。
